# Indiandevanish Games

Free online games portal by **Indiandevanish** (Gorakhpur, India) — featuring **Indian Auto Wala Rush** plus family-friendly partner games from GameMonetize and GameDistribution.

Live: https://anishgamedev.github.io/

- Add / remove games: edit `games.json` → see **ADD-A-GAME.md**
- Site name, contact email, Google verification, revenue IDs: `config.json`
- Pages, sitemap.xml, robots.txt, manifest are generated by `node tools/build.mjs` (runs automatically on GitHub via `.github/workflows/build.yml`).
- Pure static HTML/CSS/JS — no server, no npm install.
